# 测试分类与测力计验收（rdt_gauge_bench）

测试分三类，证据分开记，一类通过不能代替另一类（照 wuji-dh-ui 的证据分层）。命令都写成 `python -m rdt_gauge.cli <命令>`，下面省略前缀；连接参数（`--port COM9 --baud …`）也省略。

| 类别 | 测什么 | 什么时候 | 证据 |
|---|---|---|---|
| ① 软件离线测试（pytest） | 脚本本身对不对 | 随时，不要测力计 | 命令和退出码 |
| ② 实机调通 | 脚本和真实测力计能不能配合 | 到货后 | 每一步的输出文件（备份 JSON、修改记录、采集目录） |
| ③ 测力计验收 | 测力计合不合格（要求 A–G） | 调通以后 | 每条：结果、数值、是否通过、数据文件 |

## ① 软件离线测试

```powershell
$env:PYTHONUTF8 = '1'
.venv\Scripts\python -m pytest -q
```

- 不做模拟测力计。输入只有说明书里的报文和测试里写好的固定字节：`tests/frames.py` 按说明书的帧格式事先拼好回复，`tests/scripted_port.py` 按顺序给出；它们不看代码发了什么，请求对不对由各测试检查。
- `tests/conftest.py` 先锁死真实串口（打开和列出都报错），再导入代码。
- 图形窗口的测试（`test_window_builds_and_refreshes_offscreen`）在图形库用不了的电脑上跳过，跳过原因会打印出来。

| 测试文件 | 测什么 |
|---|---|
| `test_offline_guard.py` | 本进程和子进程都打不开、列不出串口 |
| `test_layers.py` | 按 `pyproject.toml` 的分层表：下层不导入上层、同层独立模块互不导入、每个模块都登记了分层 |
| `test_contracts.py` | 参数检查、状态位解码（说明书例子 `0x0802`）、数据行和回执 |
| `test_protocol.py` | 说明书报文的 CRC、组帧、回复解析；坏回复（少字节、改字节、地址、功能码、字节数）都被拦下；异常帧；32 位解码（包括说明书负数例子算错 1 的那处）；超时按波特率；客户端重试和不重试的情况；写回显可选 |
| `test_registers.py` | 地址不重叠；每个禁写寄存器都写不进去；可写的正好是那 13 个；测试设置；备份分块覆盖全部可读寄存器、不重复、不读只写寄存器；编码翻译 |
| `test_storage.py` | JSON 原子写、拒绝 NaN；运行目录不覆盖；CSV 单写者保序、不覆盖已有文件、队列满报错不悄悄丢、打不开文件报错；CSV 读回 |
| `test_ports.py` | 串口列表；按序列号找、和 COM 号核对；只有一个 FTDI 才自动选；扫描只发 03、异常帧也算通、打不开就停；换参数 |
| `test_capture.py` | 两种读法、换算成 N；连续 3 次失败才停并每次清缓冲；固定周期；帧间隔；统计（新值按 AD 内码、间隔分位数、均值和标准差、错误数、最小步长）；采集会话的 CSV、metadata、summary；写盘失败立即停；预览有上限并报告丢点 |
| `test_settings_ops.py` | 全部读取和翻译；和测试设置对比；计划拒绝白名单外、通信参数、超范围、读不到当前值；默认只读；写完读回；读回不对立即停；**原值在第一条写命令之前已落盘**；解锁后一定上锁；恢复只写普通白名单；改波特率/帧格式：成功、没改成换回旧参数、两边不通给恢复办法 |
| `test_raw_console.py` | 输入解析；默认只读；写只能写白名单、通信参数不让直接写；回复拆解（超时给排查办法、设备拒绝、CRC、地址、长度） |
| `test_live_plot.py` | 显示窗口内的点、新值间隔、预览丢点、原始计数；状态行；图形库不能用时给出的办法；（能用时）窗口建起来、刷新、关窗口请采集停下 |
| `test_cli.py` | 每个命令都有解析和处理；坏参数退出码 2；ports、info、backup；set 不加 --apply 不写、加了写并读回、禁写寄存器拒绝；preset-test、restore、set-link 只列计划；raw；live 采集到新目录；图形库不能用时不开始采集；stats 从 CSV 重算；设备读不到报错不崩 |

另外每批改动用"变异检查"确认关键测试真能抓到错：故意把一条安全规则改坏（例如"白名单外也能写""写之前不存原值"），对应测试必须失败，改回后全部通过。

## ② 实机调通（到货后，按顺序）

| 步 | 命令 | 看什么 |
|---|---|---|
| 1 | `ports` | 认出 FTDI 转换器、序列号；延迟不是 1 ms 就到设备管理器里改 |
| 2 | `scan --port COM9` | 找到能通的波特率、校验位、停止位、地址；记下它给的连接参数 |
| 3 | `info` | 每一项都读得到；寄存器 9、10 读不读得出（交给维护者）；单位是不是 N |
| 4 | `backup` | 出厂设置存档（以后都靠它恢复） |
| 5 | `live --label 出厂 --seconds 60`（或 `--no-plot`） | 出厂设置下的采集，作对照 |
| 6 | `raw` | 手动读几个寄存器，熟悉报文 |
| 7 | `preset-test`，确认后 `preset-test --apply` | 跟踪、清零全关，滤波关；被拒绝就加 `--unlock` |
| 8 | 断电重启后 `info` | 设置确实存住了 |
| 9 | `set ad_speed_code=…`（逐档，每档都 `live` + `stats`） | 新值速率和噪声，选噪声达标里最快的一档 |
| 10 | `backup` 后 `set-link --to-baud 921600`，确认后加 `--apply` | 断联时照提示恢复；之后连接都用新波特率 |
| 11 | `info`、`backup` | 冻结的"测试设置"存档 |

到货后先核对的几件事见 README"到货后要在实机上核对的"。

## ③ 测力计验收（要求 A–G）

要求原文：`测力计要求_20261111.md`。"版本"一列：**第一版** = 现在的脚本能测；**第二版** = 要另外加分析或接线（阶跃、频谱、砝码分级）；**手工** = 查资料或量具。

| 编号 | 要求 | 怎么测 | 命令 | 合格标准 | 版本 |
|---|---|---|---|---|---|
| A1 | 压向受力 | 查合格证；放砝码看读数方向 | `live` | 受压为正 | 第一版 |
| A2 | 满量程 ≥30 N | 查合格证；加到 30 N，看状态寄存器 8 bit6（溢出） | `live`、`info` | 不溢出 | 第一版 |
| A3 | 安全过载 ≥150% 且 >50 N | 查资料：RDF-TC10B 安全超载 150%，所以选 5 kg（约 49 N）以上 | — | 资料符合 | 手工 |
| B1 | 12 Hz 峰值 ≥97% | 阶跃响应 + 采样间隔推算；或继电器按 12 Hz 通断直接测 | 第二版 | 每一下 ≥97% | 第二版 |
| B2 | 滤波能全关、无残留平滑 | 34、35 写 0，读回，断电再读；二级、稳定滤波的地址问厂家；再看阶跃和静止自相关 | `set`、`info`；第二版 | 都能关、读回一致、无残留平滑 | 第一版（设置）+ 第二版（验证） |
| B3/B4 | 阶跃 10→90% ≤10 ms（最好 ≤5） | 分流电阻 + 光耦继电器，RTS 控制，叠加约 120 次 | 第二版 | 中位数达标 | 第二版 |
| B5 | 纯延迟 ≤10 ms 且每次相同 | 同上，从翻转到读数开始变 | 第二版 | 中位数 ≤10 ms、离散小 | 第二版 |
| C1/C2 | ≥250 个新值/s（最好 ≥1000） | 各档 AD 速度 × 波特率，空载最快读 60 s，按 AD 内码变化计数 | `live --seconds 60`、`stats` | 达标；错误 0；p99 ≤ 2×中位数 | 第一版 |
| C3 | 样本计数器或时间戳 | 查协议，现有资料没有，问厂家 | — | 有或没有 | 手工 |
| D1 | 静止噪声 ≤0.01 N | 空载、10 N 各静置 60 s | `live`、`stats` | σ ≤0.01 N | 第一版 |
| D2 | 50 Hz 波动 ≤0.01 N | 重采样成等间隔做频谱 | 第二版 `stats` | ≤0.01 N | 第二版 |
| D3 | 最小步长 ≤0.002 N | 寄存器 8（小数位）、104（单位）；数据里最小的非零差；称台分度（88）问厂家 | `info`、`stats` | ≤0.002 N | 第一版 |
| D4 | 非线性 + 重复性 ≤0.1% FS | 0–100% 分五级加载卸载，来回 3 次，最小二乘 | 第二版 | ≤0.1% FS | 第二版 |
| D5 | 30 min 蠕变有数值 | 加 60–100% FS 记 30 min，空载 30 min 对照 | `live --seconds 1800 --no-plot`、`stats` | 有明确数值 | 第一版（采集） |
| E1/E2 | 跟踪、清零类能关、能读回 | 写 0、读回、断电再读；带载上电、小砝码放 10 min、按 ZERO 键逐项验 | `preset-test`、`info`、`live` | 都能关、断电保持、验证通过 | 第一版 |
| E3 | 滤波和速率能读回 | 读 32/34/35；一级、二级、稳定滤波地址问厂家 | `info` | 都能读回 | 第一版 |
| E4 | 配置锁 | 上电后（默认锁着）不加 `--unlock` 试改滤波强度 `set filter_strength=1 --apply`：被拒说明锁也管普通设置，写进去说明锁只管通信参数（和协议写的一致）；试完 `set filter_strength=0 --apply` 改回。防误清零靠 93=0（E1 里按 ZERO 键验证），**不发置零命令**（94 在禁写清单里，脚本会拒绝） | `set` | 有锁；锁管到哪些项如实记 | 第一版 |
| E5 | 溢出、超载状态位 | 读寄存器 8 bit6、bit9；需要触发时分流电阻换约 5.6 kΩ | `info`、`live` | 能置位 | 第一版（读）+ 第二版（触发） |
| F1 | Modbus 03 读、32 位整数 | 读 80–81 解码，放砝码核对 | `info`、`raw` | 解码正确 | 第一版 |
| F2 | 协议完整 | 对照 B2、E1、E3 用到的每一项 | — | 齐全（缺的问厂家） | 手工 |
| F3 | FTDI、延迟 1 ms、序列号唯一 | VID 0403、有序列号；设备管理器设 1 ms | `ports` | 都满足 | 第一版 |
| F4 | 和原测力计同协议 | 读寄存器 0–10 交给维护者 | `info`、`raw` | 9 ≥1、10 能判断字序 | 第一版 |
| G1 | 装得进现有夹具 | 卡尺、螺纹规；RDF-TC10B 是 M4 螺纹；试装找维护者 | — | 对得上 | 手工 |
| G2 | 满载变形量、固有频率 | 问厂家；也可示波器接 SIG+ 轻敲看振荡 | — | 资料齐全 | 手工 |

`stats` 打印的"达标/不达标"只对对应的测试有意义（D1 要空载静置，C1 要最快速度读），其他采集的判断不能当验收结论。
